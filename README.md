# statdatathon-microdata-analytics
# Комплексный анализ синтетических микроданных Бюро национальной статистики РК (2021–2024) 🇰🇿

##  О проекте и команде
Название команды: InsightX. Состав: Акжанов Арнай, Бибитов Берикбол, Смоляр Арина, Таубаев Арсен, Тлеубергенов Темирлан. Наш проект посвящен глубокому социально-экономическому исследованию уровня жизни, жилищных условий и качества жизни населения Казахстана. Мы обработали масштабный массив данных объемом **более 72 миллионов строк**, распределенных по вложенным хронологическим структурам обследований домашних хозяйств.

В рамках дататона наша команда реализовала гибридный стек для достижения максимальной производительности:
* **SQL-аналитика (СУБД DuckDB):** Использовалась для молниеносной агрегации Big Data, трансформации и сопоставления широких матриц опросов (44 сквозных индикатора) без перегрузки оперативной памяти.
* **Python-аналитика:** Применялась для предварительной обработки файлов, автоматизации проверки структур, построения финальных прогнозных моделей и визуализаций.
* **R-аналитика:** Использовалась для проведения углубленного статистического анализа, верификации распределений и построения дополнительных аналитических графиков.

---

##  Технологический стек и AI-ассистирование
* **Database Engine:** DuckDB (векторная аналитическая СУБД для работы с Big Data на локальных машинах)
* **Языки запросов и программирования:** SQL (расширенный синтаксис DuckDB), Python 3.10
* **Ключевые инструменты SQL:** `UNPIVOT` для нормализации анкетных шкал, реляционные справочники сопоставления кодов, оптимизированные `LEFT JOIN` по сквозным ключам `NOMER`.
* **Библиотеки Python:** Pandas, NumPy, Matplotlib, Seaborn.
* **Пакеты R:** tidyverse.
* **AI-Assisted Development:** При проектировании архитектуры базы данных, оптимизации тяжелых запросов и написании кода активно использовались **ИИ-агенты (в частности, Claude)**, что позволило кратно сократить время разработки (Time-to-Market) аналитического решения.

##  Структура обработанных данных БНС АСПиР РК
Мы провели исследование по трем ключевым модулям государственных статистических наблюдений домашних хозяйств (группа форм `d*`):
1. **Жилищные условия (`d006 / rio.csv`):** Инфраструктурный паспорт хозяйств (площадь, количество комнат, доступ к центральному отоплению, водопроводу и фиксированному интернету, обеспеченность автомобилями).
2. **Бюджеты домашних хозяйств (`d004 / kv_vopr1–kv_vopr7`):** Финансовая матрица по 7 ключевым статьям ежеквартальных расходов семей (вещи, коммунальные услуги, связь, образование, здравоохранение, транспорт, культура).
3. **Демографический портрет и качество жизни (`d008 / d002`):** Социальный срез (состав семей, уровень образования, семейное положение) и глобальный опрос удовлетворенности качеством жизни (44 сквозные шкалы).

## Как воспроизвести

Ноутбук `InsightX_Data_to_Policy.ipynb` написан для Google Colab. Исходные данные (синтетические микроданные БНС РК за 2021–2024 годы) в репозиторий не включены: их объём превышает 72 млн строк. В файле сохранены результаты всех ячеек (таблицы и графики), поэтому их можно посмотреть без запуска.

### 1. Подготовка данных
1. Скачайте архив данных организаторов `synthetic_microdata_2021-2024_20260921` и распакуйте его на Google Drive в папку `MyDrive/Datathon/`.
2. Положите в ту же папку `MyDrive/Datathon/` SQL-файлы `D002.sql` и `D008.sql`. Они используются для агрегации модулей d002 и d008. https://drive.google.com/drive/folders/1WDETBYVRtsYj_-N_rCIw3Cgn2Y5tWWVH?usp=sharing
3. Если данные лежат в другой папке, замените путь `/content/drive/MyDrive/Datathon` в ячейках загрузки. Он указан в начале блоков D002, D004, D006, D008 и H3.

Ожидаемая структура:

    MyDrive/Datathon/
    ├── D002.sql
    ├── D008.sql
    └── synthetic_microdata_2021-2024_20260921/
        ├── d002/  d004/  d006/  d008/

### 2. Окружение
- Среда: Google Colab (Python 3 и R через `rpy2`).
- Python-библиотеки: `pandas`, `numpy`, `matplotlib`, `seaborn`, `duckdb`, `duckdb-engine`.
- R-пакеты: `tidyverse`, `broom` (устанавливаются автоматически в ячейках блоков D006 и H2).
- Первые ячейки ноутбука сами подключают R-расширение, устанавливают DuckDB и монтируют Google Drive.

### 3. Порядок запуска
Запускайте ячейки сверху вниз: блоки зависят друг от друга.

| Блок | Что делает | Зависит от |
|---|---|---|
| D002 | Оценки удовлетворённости качеством жизни | Подготовка данных |
| D004 | Расходы домохозяйств, описательная статистика | Подготовка данных |
| D006 | Жильё и инфраструктура (R) | Подготовка данных |
| D008 | Образование, занятость, семейное положение | `D008.sql` |
| H1 | Дефицит бюджета по децилям дохода | **D004** (переменные `d004_path`, `expenses_valid`, `show`) |
| H2 | Влияние состава семьи и условий жилья | **D006** (таблица `rio_all`) |
| H3 | Финансовая уязвимость и качество жизни | Самостоятельный блок (DuckDB) |

Блок H3 можно запускать отдельно. Блоки H1 и H2 нельзя запускать без D004 и D006.

### 4. Результаты
Промежуточные таблицы сохраняются на Drive в папки `results_d004/` и `h3_results/` и в файл `d002_processed_output.csv`.

### 5. Особенности расчётов
- Расчёты по D004 выполняются без весов и без поправки на инфляцию. Продовольственных расходов в D004 нет.
- Тяжёлые таблицы читаются потоково через DuckDB, без полной загрузки в память.
